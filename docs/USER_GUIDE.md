## 启动系统

### 1. 启动后端 API
```bash
cd C:\Users\16565\Documents\AI_work\fitfactory-os
python3 -m uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
```

### 2. 启动前端界面（另一个终端）
```bash
python3 -m streamlit run src/ui/app.py
```

浏览器自动打开 `http://localhost:8501`

### 3. 手机访问（同一 WiFi）
```
手机浏览器 → http://[电脑IP]:8501
```

## 典型工作流

### 收到新订单
1. 打开「订单管理」→ 新增订单
2. 切换到「生产排单」→ 自动排产
3. AI 自动选产线 + 日期，按需调整

### 客户催单
1. 打开「AI 助手」
2. 输入：`SO-20260601 做到哪了`
3. AI 自动查数据库回复进度

### 客户要插单
1. 打开「生产排单」→ 插单模拟
2. 输入款号、件数、期望日期
3. 系统列出受影响订单和延期天数

### 月底算工资
1. 打开「计件工资」→ 工资汇总
2. 选择年月 → 自动汇总
3. 异常标记自动识别
