## 2. 技术选型决策记录

### 2.1 为什么选 Streamlit 而不是直接上 React？

| 维度 | Streamlit | React + Tailwind |
| --- | --- | --- |
| 开发速度 | 一个人 1 天出可用版本 | 至少 3~5 天 |
| 学习成本 | 纯 Python，零前端知识 | 需要 JS/TS + 状态管理 |
| 适合场景 | 内部工具、快速验证 | 多用户 SaaS 产品 |
| UI 灵活度 | 受限（组件固定） | 完全自定义 |
| **决策** | ✅ **Phase 1 用 Streamlit** | Phase 2 迁移到 React |

**切换条件**：当用户数 > 5 或需要精细化交互（如甘特图拖拽）时启动 Phase 2。

### 2.2 为什么选 SQLite 而不是直接上 PostgreSQL？

- SQLite 零配置，不需要单独安装数据库服务
- 服装厂单机场景完全够用（几百 MB 数据量）
- SQLAlchemy ORM 层隔离 → 后期一条连接串改 PostgreSQL
- **切换时机**：需要多用户并发写入时迁移

### 2.3 为什么选 Chroma 而不是其他向量数据库？

- 纯 Python，嵌入 FastAPI 进程，零运维
- 轻量级，适合本地部署
- API 简洁，与 LangChain 无缝集成
- **切换时机**：需要生产级 SaaS 时迁移到 Cloudflare Vectorize

### 2.4 为什么选 DeepSeek 而不是其他大模型？

- **Function Calling 稳定**：这是 Agent 串联系列的基石
- **中文理解能力强**：服装厂术语（"蕾丝""肩带""背钩"）理解准确
- **成本低**：适合高频调用的工厂场景
- **API 兼容 OpenAI 格式**：方便后期替换

## 4. 部署方案（含移动端访问路径）

### 4.1 Phase 1-2：PC 本地单机

```
┌─────────────────────────────────────────┐
│           Windows PC (厂长办公室)         │
│                                          │
│  ┌──────────────────────────────────┐   │
│  │  FastAPI :8000                   │   │
│  │  ├── Streamlit :8501             │   │
│  │  ├── SQLite (本地文件)           │   │
│  │  ├── Chroma (进程内)             │   │
│  │  └── DeepSeek API (外网调用)     │   │
│  └──────────────────────────────────┘   │
│                                          │
│  仅 PC 浏览器 → http://localhost:8501     │
│  📱 手机不可用                            │
└─────────────────────────────────────────┘
```

### 4.2 Phase 3：局域网手机可用

```
┌─────────────────────────────────────────────────────────────┐
│                    工厂 WiFi 局域网                           │
│                                                             │
│  ┌──────────────────────────────────────┐                   │
│  │  厂长 PC (192.168.1.100)             │                   │
│  │  FastAPI + Streamlit                 │                   │
│  │  uvicorn --host 0.0.0.0 :8000       │                   │
│  └──────────────┬───────────────────────┘                   │
│                 │                                            │
│    ┌────────────┼────────────┐                               │
│    ▼            ▼            ▼                               │
│  PC 浏览器    📱 手机A     📱 手机B                          │
│  :8501       :8501        :8501                             │
│              (横屏勉强)   (横屏勉强)                          │
│              ↓ 车间查进度  ↓ 仓库看物料                       │
└─────────────────────────────────────────────────────────────┘

启动命令：
  uvicorn src.main:app --host 0.0.0.0 --port 8000
  streamlit run src/ui/app.py --server.address 0.0.0.0 --server.port 8501
  
手机访问：
  连上工厂 WiFi → 浏览器输入 http://192.168.1.100:8501
```

### 4.3 Phase 4：公网随时随地（Cloudflare 全栈）

```
                 📱 手机浏览器 (4G/5G/任何网络)
                 💻 PC 浏览器
                         │
                         ▼
              https://fitfactory.app
                         │
              ┌──────────┴──────────┐
              │  Cloudflare Pages   │
              │  (React PWA 静态)   │
              │  + Service Worker   │
              │  + 可添加到主屏幕    │
              └──────────┬──────────┘
                         │ API 调用
                         ▼
              ┌──────────────────────┐
              │  Cloudflare Workers  │
              │  (FastAPI → Worker)  │
              └──────────┬───────────┘
                         │
          ┌──────────────┼──────────────┐
          ▼              ▼              ▼
    D1 (SQLite)    Vectorize       R2 (文件)
    (关系数据)     (向量检索)       (报表导出)
```

**PWA 关键特性**：
- `manifest.json`：定义应用名、图标、全屏模式
- Service Worker：离线缓存，车间信号差也能看已加载数据
- "添加到主屏幕"：一次操作，以后点图标就像打开 App
